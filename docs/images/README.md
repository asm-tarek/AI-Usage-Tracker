The chat pages behind the widget are simple stand-ins built for screenshots, not
real claude.ai or chatgpt.com pages, and the numbers are made up. Everything
inside the widget, the options page and the popup is the real extension.
For the README hero image, a screenshot from your own account will look better
and avoids any question about the mock pages.
